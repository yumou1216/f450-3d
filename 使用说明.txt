F450 四旋翼 · 3D 拆解页面 使用说明
================================================

★ 在线网址（已上线 2026-10-24）：
  https://yumou1216.github.io/f450-3d/
  （GitHub Pages 免费托管。国内访问时好时坏，打不开就换
   WiFi/热点切换重试；稳定国内版等 Gitee 实名审核通过后
   在 Gitee 仓库「服务→Gitee Pages」点启动，链接形如
   https://yumou1216.gitee.io/f450-3d/ ）

文件夹里的三个文件缺一不可（整个文件夹要一起移动/发送）：
  index.html        页面（入口）
  main.js           3D 模型和交互逻辑
  lib/three.min.js  Three.js 引擎（本地库，所以断网也能用）

★ 以后怎么更新线上页面（改了 main.js 或 index.html 之后）：
  在本文件夹地址栏输入 cmd 回车，然后执行：
    git add .
    git commit -m "更新说明"
    git push gitee main        （推 Gitee）
  GitHub 那边推送需要令牌当密码（30天后过期，过期就去
  GitHub → Settings → Developer settings → Personal access
  tokens 重新生成一个，勾选 repo 权限）：
    git -c credential.helper= push "https://yumou1216:你的令牌@github.com/yumou1216/f450-3d.git" main
  推送后 GitHub Pages 一两分钟内自动更新；Gitee Pages 需要去
  网页上手动点一次「更新」。

一、自己打开（最简单，不用联网）
------------------------------------------------
直接双击 index.html，用 Edge 或 Chrome 打开即可。
不需要启动任何服务器，断网状态也能正常玩。


二、同一 WiFi 下给别人看（手机也能开）
------------------------------------------------
1. 电脑上先启动一个小服务器：
   在本文件夹的地址栏输入  cmd  回车，黑窗口里输入：
       python -m http.server 8123
   （如果 Windows 弹出防火墙提示，点"允许"）

2. 手机连上和电脑同一个 WiFi，手机浏览器打开：
       http://192.168.135.40:8123
   （192.168.135.40 是电脑当前的内网地址，路由器重分配后会变；
    可在 cmd 里输入 ipconfig 查看"IPv4 地址"获得最新值）

3. 用完在黑窗口按 Ctrl+C 关闭服务器。


三、发链接给远方的人
------------------------------------------------
在线网址见最上方 ★。也可以把整个文件夹压缩成 zip 发微信，
对方电脑解压后双击 index.html 就能玩（手机上解压较麻烦，
建议直接发在线链接）。


四、页面操作速查
------------------------------------------------
鼠标：拖动旋转 · 滚轮缩放 · 右键平移 · 点击部件看详情
按键：空格 = 拆解/装配   X = X光   L = 标注   D = 自动演示   R = 复位视角
手机：单指旋转 · 双指缩放 · 点部件看详情

部件数据来自实际组装记录（2026-10，余莉艳项目清单）。
