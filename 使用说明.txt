F450 四旋翼 · 3D 拆解页面 使用说明
================================================

文件夹里的三个文件缺一不可（整个文件夹要一起移动/发送）：
  index.html        页面（入口）
  main.js           3D 模型和交互逻辑
  lib/three.min.js  Three.js 引擎（本地库，所以断网也能用）


一、自己打开（最简单，不用联网）
------------------------------------------------
直接双击 index.html，用 Edge 或 Chrome 打开即可。
不需要启动任何服务器，断网状态也能正常玩。


二、同一 WiFi 下给别人看（手机也能开）
------------------------------------------------
1. 电脑上先启动一个小服务器：
   在本文件夹的地址栏输入  cmd  回车，黑窗口里输入：
       python -m http.server 8123
   （如果 Windows 弹出防火墙提示，点"允许"）

2. 手机连上和电脑同一个 WiFi，手机浏览器打开：
       http://192.168.135.40:8123
   （192.168.135.40 是电脑当前的内网地址，路由器重分配后会变；
    可在 cmd 里输入 ipconfig 查看"IPv4 地址"获得最新值）

3. 用完在黑窗口按 Ctrl+C 关闭服务器。


三、发链接给远方的人（推荐，微信点开就能玩）
------------------------------------------------
把页面放到免费静态托管上，得到一个网址，手机电脑都能打开。
任选其一：
  · Gitee Pages（国内快）：注册 gitee.com → 新建仓库 →
    上传这三个文件 → 服务 → Gitee Pages → 开启
  · GitHub Pages：注册 github.com → 新建仓库 → 上传文件 →
    Settings → Pages → 选择 main 分支开启
  · Vercel：vercel.com → 登录 → 直接把整个文件夹拖进网页 →
    自动生成链接

注意：托管时上传的是"文件夹里的内容"（index.html 在最顶层），
不要把整个文件夹套一层再传。


四、页面操作速查
------------------------------------------------
鼠标：拖动旋转 · 滚轮缩放 · 右键平移 · 点击部件看详情
按键：空格 = 拆解/装配   X = X光   L = 标注   D = 自动演示   R = 复位视角
手机：单指旋转 · 双指缩放 · 点部件看详情

部件数据来自实际组装记录（2026-10，余莉艳项目清单）。
